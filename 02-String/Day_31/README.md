- What is the difference between one character and multiple characters?

Without this foundation, advanced String algorithms become difficult to understand.

---

# 💡 Core Idea

A **String** is a sequence (collection) of characters.

Examples:

```text
"Ansh"

↓

A
n
s
h
```

Each individual letter is called a **Character**.

# ⚖️ Character vs String

| Character | String |
|------------|---------|
| Stores one character | Stores multiple characters |
| Uses Single Quotes | Uses Double Quotes |
| Data Type = `char` | Data Type = `String` |
| Example: `'A'` | Example: `"Ansh"` |

# 🧠 Developer Notes

- Every String is made up of Characters.
- Character and String are different data types.
- A String may contain one character or thousands of characters.
- `"A"` is a String.
- `'A'` is a Character.
- Never confuse syntax with data type.
