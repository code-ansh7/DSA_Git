# Important Concepts

### Character

Stores only one character.

Example

```java
'A'
```

---

### String

Stores a sequence of characters.

Example

```java
"Flutter"
```

---

### length()

Returns the total number of characters present inside a String.

---

# Developer Notes

- Character and String are different data types.
- Every String is made up of Characters.
- A String may contain one character or many characters.
- Understanding fundamentals makes advanced String algorithms easier.
- Focus on concepts instead of memorizing syntax.
